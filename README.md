## Task 4 – WeatherNow Weather Dashboard

**Folder:** `Task_4_WeatherNow/`
**Live Demo:** https://weathernow-phi-five.vercel.app/

A real-time weather dashboard featuring global city search, current weather conditions, weather telemetry, and a five-day forecast.

The application uses a serverless backend to communicate with the OpenWeatherMap API. The API key is configured through an environment variable and is not included in this public repository.

### Local Setup

1. Install Node.js.
2. Clone this repository.
3. Navigate to `Task_4_WeatherNow/`.
4. Install dependencies:

   ```bash
   npm install


5. Configure the OPENWEATHER_API_KEY environment variable in your deployment environment.
6. Deploy using Vercel or configure an appropriate local serverless development environment.
### API Endpoint
GET /api/weather?city=Accra


The endpoint retrieves current weather information and forecast data for the requested city.
